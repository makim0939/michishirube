# ChatGPT への画像生成の依頼（ラテ帳の型の見本）

入力画像は `input/` の6枚（アプリで今使っている型の分だけ）です（1024×1024 に拡大済み。元は 320×320 で粗い）。
使い方は、いちばん下の「進め方」を見てください。

---

## 1. 最初に送る依頼文（共通・スタイルの指示）

最初のメッセージに、`input/00-all.png`（6枚の一覧）と `input/01-rosetta.png` を添付して、下の文を送ります。

```
添付の画像は、ラテアートのアプリ「ラテ帳」で使っている、ラテアートの型の見本イラストです。
いまの画像は解像度が低く、細部がつぶれています。
同じ構図・同じ型のまま、解像度と細部を上げて作り直してください。
雰囲気は、いまのやわらかいイラスト調と、粒子感のあるテクスチャを保ち、ラテアートの形だけを、より本物らしくします。

【変えないこと（いちばん大事）】
- 真上（俯瞰）から見た構図。カップを画面の中央に置き、カップの取っ手は右下
- ソーサー（白い皿）が、カップの周りに見える。左上の隅に、木のテーブルがわずかに見える
- 右下に、窓からの光でできる、やわらかいカップの影
- カップの中の模様の「型」。入力画像の模様のシルエット・向き・位置・大きさを変えない
  （模様を別のデザインにしない。ラテアートとして成り立つ形を保つ）
- 正方形（1:1）、1024×1024

【絵の雰囲気（変えないこと）】
- いまの、写真ではなく「やわらかいイラスト調」の雰囲気を保つ。写真のようなリアルな質感にはしない
- いまの、粒子感・ざらざらしたテクスチャ（紙や粗い布のような、細かい粒）は、味なので残す。
  消さずに、細かさをそろえて、全体にむらなくのせる
- 消すのは、ぼやけ・にじみ・ブロック状のノイズ（画像の圧縮による劣化）だけ

【ラテアートの形（よりリアルにする）】
- 型のシルエット・向き・位置・大きさは、入力のまま変えない
- そのうえで、線や縁を、実際のラテアートに近づける。ミルクが流れてできた、
  すこし有機的でやわらかい縁、わずかな厚み、自然なゆらぎ、線の太さの強弱。
  定規やペンで描いたような、機械的で均一な線にしない。完全な左右対称にもしない
- 白い部分は、ミルクの層が重なった、ふんわりした厚みを、色の濃淡で表す

【良くすること】
- 解像度を上げ、細部（カップの縁、ミルクの線、木目）を、にじまず鮮明にする
- ミルクフォームは、なめらかなツヤと、ほんのわずかな立体感を出す
- エスプレッソのクレマは、中心が明るく、外側が濃い、自然なグラデーション。
  細かな気泡が少し見える
- カップとソーサーは、白い陶器の質感（わずかな光沢、縁の反射、やさしい陰影）
- 光は、窓辺の自然光。あたたかい色合い（ベージュ・キャラメル・ミルクの白）。
  白飛びや、黒つぶれをさせない

【入れないこと】
- 文字、ロゴ、透かし、手、スプーン、豆、そのほかの小物
- 入力にない模様の追加、カップの種類の変更

まずは、添付の「ロゼッタ（01-rosetta.png）」だけを作ってください。
スタイルが決まったら、同じ設定で、ほかの型を1枚ずつ頼みます。
```

---

## 2. 型ごとの依頼（スタイルが決まったあと、1枚ずつ）

各型の入力画像（`input/` の該当ファイル）を添付して、次の形で送ります。

```
同じスタイル・同じ構図で、添付の画像（<型の名前>）を作り直してください。
模様の形・向き・位置・大きさは、添付のままにしてください。
<型ごとの補足>
```

型ごとの補足（この中から、該当のものを `<型ごとの補足>` に貼ります）。補足は目安です。**入力画像の模様が正で、文章と食い違うときは、画像を優先する**と、依頼に書き添えてください。

| ファイル | 型の名前 | 型ごとの補足 |
|---|---|---|
| 01-rosetta.png | ロゼッタ（リーフ） | ハートの形の先端が上。その下に、葉脈のような左右対称の細い線が重なる。外側に、葉を包む同心の弧がある。いちばん下に細い軸 |
| 02-heart.png | ハート | 単純な1つのハート。先端が下で、そこから細い線が少し下に伸びる。ほかの模様はない |
| 03-tulip2.png | チューリップ | 上にハート、その下に、三日月（カップ）のような形がひとつ、いちばん下に細い軸 |
| 04-layerheart.png | レイヤーハート | 大きなハートの中に、同じ形の小さなハートの線が、7本ほど内側へ同心状に重なる。先端が下 |
| 05-wing.png | ウイングチューリップ | 上にハート形の葉、その左右に、翼のように広がる弧の線が数本。下に細い軸 |
| 06-swan.png | スワン | 左側に、曲がった首と小さな頭。右側に、羽のような層の模様。下の方に、水面のような細い弧の線。入力のとおりの配置 |

## 2-2. 2枚目以降の頼み方（ロゼッタで決めた1枚を、基準にする）

ロゼッタの仕上がりに合意したら、次の型からは、**合意した1枚（基準画像）と、その型の入力画像の2枚**を添付して頼みます。
こうすると、カップ・ソーサー・木のテーブル・光・質感がそろい、変わるのは模様だけになります。

```
1枚目の添付は、合意したスタイルの基準画像（ロゼッタ）です。2枚目の添付は、今回作る型（<型の名前>）の入力画像です。
基準画像と、カップ・ソーサー・木のテーブル・光・質感・ラテの色・画角・カップの位置と大きさを、完全に同じにして、
ラテアートの模様だけを、2枚目の入力画像の型に差し替えてください。
模様のシルエット・向き・位置・大きさは、2枚目の入力のままにして、線や縁だけを、基準画像と同じ、ミルクが流れたような自然な質感にします。
<型ごとの補足>
正方形（1:1）、1024×1024。
```

ここで大事なのは、**6枚で、カップとソーサーの位置と大きさがまったく同じ**になることです。
一覧のサムネイルや丸い切り抜きで使うときに、こちらで、カップの周りを同じ範囲で切り出して大きくします（元の画角が同じなら、きれいにそろいます）。

---

## 3. 進め方（うまくいくコツ）

1. **最初の1枚（ロゼッタ）で、スタイルを決める。** 気に入るまで、同じチャットで直しを頼む。
   直しの例：「もう少し明るく」「粒子感をもう少し控えめに」「粒子感をもう少し残して」「ミルクの白を、少しクリーム色に」「模様のエッジをよりくっきり」
2. **同じチャットで、1枚ずつ頼む。** 1回の依頼で何枚も頼むと、スタイルと構図がずれやすい。
3. **模様の形が変わったら、作り直してもらう。** 「模様の形が、入力と違う。添付のとおりにして」と、入力画像を添えて頼む。
   形が大きく崩れる場合は、「入力画像のシルエットに、重ねるつもりで」と言い添える。
4. **構図がそろっているか確認する。** 6枚を並べたとき、カップの位置・大きさ・取っ手の向き・影が同じになっていること。
   ずれる場合は、「カップの位置と大きさを、添付の `00-all.png` の画像と同じに」と頼む。
5. **仕上がりは、1024×1024 の PNG で受け取る。** ファイルの名前は、入力と同じ（`rosetta.png` など）にしておくと、取り込みが楽。

## 4. できあがったら

出来上がった画像を、6枚フォルダにまとめて、Claude に渡してください。
アプリに入れる形（640px 程度の WebP に縮小して、`public/world/patterns/` へ）は、こちらで作ります。
アプリでは、正方形の角丸（型の一覧）と丸い切り抜き（ホームの型のカード）で表示されます。
カップの縁や影が、切り抜きで欠けないよう、カップが余白に収まっていることを確認します。

## 5. 補足

- 作るのは、アプリで今使っている6種類（ロゼッタ・ハート・チューリップ・レイヤーハート・ウイングチューリップ・スワン）だけです（使っていない型の見本は作りません）。
- 窓辺の光の背景（`public/world/light/`：朝・昼・夕・夜の4枚）も、同じ方法で作り直せます。必要になったら、別の依頼文を作ります。
- `references/` にある、お手本のラテアートの写真（ロゼッタ.jpeg など）は、他の人が撮った写真なので、この依頼には含めていません。
