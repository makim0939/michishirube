# 記録がないときのホーム画面の背景（窓辺の光・4枚）：ChatGPT への依頼

添付する画像：`input/` の4枚と、一覧 `00-all.png`
（朝・昼・夕・夜。いまは 780×860 で、粗い）

使われる場所：写真が1枚もないとき、ホーム画面の上の大きな画像として出ます。
開いた時刻で、4枚が切り替わります（朝 5–10時、昼 10–16時、夕 16–19時、夜 19–5時）。

---

## 1. 最初に送る依頼文（共通・スタイルの指示）

`input/00-all.png` と `input/01-morning.png` を添付して、次の文を送ります。

```
添付の画像は、ラテアートの練習記録アプリ「ラテ帳」のホーム画面の背景です（朝・昼・夕・夜の4枚。一覧が1枚目）。
解像度が低く、細部がつぶれているので、同じ構図・同じ雰囲気のまま、解像度と細部を上げて作り直してください。
雰囲気は、いまのやわらかいイラスト調と、粒子感のあるテクスチャを保ち、ラテアートの形だけを、より本物らしくします。

【変えないこと（いちばん大事）】
- 真上（俯瞰）から見た構図。カップとソーサーは、画像の中央に置く
- ソーサーの上に、カップ。取っ手は右下。ラテアートの模様のシルエット・位置は、入力のまま
- 下地は、明るい木のテーブル（横に走る木目）
- 光と影の雰囲気は、入力のとおり（朝・昼・夕・夜で、それぞれ違う）
- カップ・ソーサーの大きさと位置。画像の左右は、あとで少し切り取られるので、
  カップ全体が中央の80%に収まるようにする
- 正方形（1:1）、1024×1024

【絵の雰囲気（変えないこと）】
- いまの、写真ではなく「やわらかいイラスト調」の雰囲気を保つ。写真のようなリアルな質感にはしない
- いまの、粒子感・ざらざらしたテクスチャ（紙や粗い布のような、細かい粒）は、味なので残す。
  消さずに、細かさをそろえて、全体にむらなくのせる
- 消すのは、ぼやけ・にじみ・ブロック状のノイズ（画像の圧縮による劣化）だけ

【ラテアートの形（よりリアルにする）】
- 模様のシルエット・向き・位置・大きさは、入力のまま変えない
- そのうえで、線や縁を、実際のラテアートに近づける。ミルクが流れてできた、
  すこし有機的でやわらかい縁、わずかな厚み、自然なゆらぎ、線の太さの強弱。
  定規やペンで描いたような、機械的で均一な線にしない。完全な左右対称にもしない
- 白い部分は、ミルクの層が重なった、ふんわりした厚みを、色の濃淡で表す

【良くすること】
- 解像度を上げ、細部を、にじまず鮮明にする
- 木のテーブルは、細かい木目と、ほどよいツヤ・ムラ（いまの、ざらっとした質感を残す）
- 白い陶器（カップとソーサー）は、わずかな光沢と、縁のやさしい反射と陰影
- ミルクフォームは、なめらかなツヤと、わずかな立体感。模様のエッジは、にじまずくっきり
- クレマは、中心が明るく、外側が濃い、自然なグラデーション
- 光は、窓辺の自然光。あたたかい色合い。白飛びと黒つぶれをさせない

【入れないこと】
- 文字、ロゴ、透かし、手、スプーン、豆、そのほかの小物
- 入力にない模様の追加、カップの種類の変更

まずは、添付の「朝（01-morning.png）」だけを作ってください。
スタイルが決まったら、同じ設定で、昼・夕・夜を1枚ずつ頼みます。
```

---

## 2. 時間帯ごとの依頼（スタイルが決まったあと、1枚ずつ）

各画像（`input/` の該当ファイル）を添付して、次の形で送ります。

```
同じスタイル・同じ構図で、添付の画像（<時間帯>）を作り直してください。
カップの位置・模様・光と影の向きは、添付のままにしてください。
<時間帯ごとの補足>
```

| ファイル | 時間帯 | 時間帯ごとの補足 |
|---|---|---|
| 01-morning.png | 朝 | 左上から差す、すがすがしい朝の光。左上に、植物の葉の影がうっすら落ちる。斜めに走る窓枠の影の帯が、右下に伸びる。模様は、ロゼッタ |
| 02-noon.png | 昼 | 明るく、均一でやわらかい光。影はほとんどなく、ソーサーの下にだけ、うすい影。木目がいちばんはっきり見える。模様は、チューリップ |
| 03-evening.png | 夕 | 低い位置からの、あたたかいオレンジ色の光。左から差し込み、斜めに長い影が伸びる。木の色が深い飴色。模様は、ハート |
| 04-night.png | 夜 | 暗めで、あたたかい照明の灯り。周囲は暗く、中央のカップに、やさしい光が集まる（四隅が暗いビネット）。木は暗い茶色。模様は、スワン |

補足は目安です。**入力画像が正で、文章と食い違うときは、画像を優先する**と、依頼に書き添えてください。

## 3. 進め方（うまくいくコツ）

1. **最初の1枚（朝）で、スタイルを決める。** 気に入るまで、同じチャットで直しを頼む。
   直しの例：「木目をもっと細かく」「粒子感をもう少し控えめに」「粒子感をもう少し残して」「ミルクの白を少しクリーム色に」
2. **同じチャットで、1枚ずつ頼む。** まとめて頼むと、構図がずれやすい。
3. **4枚を並べて、そろっているか確認する。** カップとソーサーの位置・大きさ・取っ手の向き、木目の向きと太さが、4枚で同じ。
   ずれたら、「カップの位置と大きさを、添付の 00-all.png と同じに」と頼む。
4. **模様の形が変わったら、作り直してもらう。** 「模様の形が、入力と違う。添付のとおりにして」と頼む。
5. 仕上がりは、**1024×1024 の PNG** で、名前は `morning.png`・`noon.png`・`evening.png`・`night.png` にして受け取る。
