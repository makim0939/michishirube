# アプリのアイコン：ChatGPT への依頼

添付する画像：`input/icon-current.png`（いまのアイコン。1024×1024）

方針：いまのアイコンの絵（真上から見た、ロゼッタのラテと木のテーブル）をそのまま活かして、
**小さく表示しても分かる形**に整える。新しい図柄にはしない。

---

## 依頼文（そのまま貼る）

`input/icon-current.png` を添付して、次の文を送ります。

```
添付の画像は、ラテアートの練習記録アプリ「ラテ帳」のアイコンです。
同じ絵（真上から見た、ロゼッタのラテと木のテーブル）のまま、アプリのアイコンとして完成度の高い画像に作り直してください。
雰囲気は、いまのやわらかいイラスト調と、粒子感のあるテクスチャを保ち、ラテアートの形だけを、より本物らしくします。

【アプリのアイコンとしての条件（大事）】
- 正方形（1:1）、1024×1024、PNG
- 背景は透明にせず、四隅まで木のテーブルで埋める
- 角は丸くしない（丸みは、スマホ側で付く）。枠線、影の外枠、ふちどりも付けない
- カップ全体（取っ手も含む）が、画像の中央70%の範囲に収まるように、いまより小さく置く
  （スマホで丸や角丸に切り抜かれても、カップが欠けないようにするため）
- 文字・ロゴ・透かしは入れない
- 60ピクセルほどの小ささで見ても、「ロゼッタのラテアート」と分かるように、
  白いミルクの模様と、茶色のクレマのコントラストを、はっきりさせる

【絵の内容（変えないこと）】
- 真上（俯瞰）から見た構図。カップは画像の中央、取っ手は右下
- 木のテーブルの上。左上に、植物の葉の影がうっすら落ちる。あたたかい窓辺の自然光
- カップの中は、ロゼッタ（葉の形）。ハート形の先端が上、左右対称の葉脈、外側を包む同心の弧、下に細い軸。
  入力の模様のシルエット・向き・位置を変えない（線の質感だけ、本物らしくする）

【絵の雰囲気（変えないこと）】
- いまの、写真ではなく「やわらかいイラスト調」の雰囲気を保つ。写真のようなリアルな質感にはしない
- いまの、粒子感・ざらざらしたテクスチャ（紙や粗い布のような、細かい粒）は、味なので残す。
  消さずに、細かさをそろえて、全体にむらなくのせる
- 消すのは、ぼやけ・にじみ・ブロック状のノイズ（画像の圧縮による劣化）だけ

【ラテアートの形（よりリアルにする）】
- ロゼッタのシルエット・向き・位置・大きさは、入力のまま変えない
- そのうえで、線や縁を、実際のラテアートに近づける。ミルクが流れてできた、
  すこし有機的でやわらかい縁、わずかな厚み、自然なゆらぎ、線の太さの強弱。
  定規やペンで描いたような、機械的で均一な線にしない。完全な左右対称にもしない
- 白い部分は、ミルクの層が重なった、ふんわりした厚みを、色の濃淡で表す

【良くすること】
- 解像度を上げ、細部を、にじまず鮮明にする
- ミルクフォームの、なめらかなツヤと、わずかな立体感
- クレマは、中心が明るく、外側が濃い、自然なグラデーション
- 白い陶器のカップは、わずかな光沢と、縁のやさしい反射と陰影
- 色は、あたたかいベージュ・キャラメル・ミルクの白。白飛びと黒つぶれをさせない

3つのパターンを作ってください（1つの返事に、3枚）：
A. いまの構図のまま、品質だけを上げたもの
B. カップを少し小さくして、まわりのテーブルを多めに見せたもの
C. カップを少し大きくし、模様をより目立たせたもの（ただし、カップが中央70%に収まること）
```

---

## 進め方

1. 3枚から、いちばんよいものを選ぶ。気に入らなければ、「A をもう少し明るく」「模様のコントラストを強く」などと直しを頼む。
2. 選んだ画像は、**1024×1024 の PNG** で受け取る。
3. 選んだ画像を、Claude に渡す。こちらで次を作って、アプリに入れる。
   - iOS のアイコン（1024px）
   - Android のアイコン（前景と背景。丸・角丸・しずく型の切り抜きに対応）
   - Web 版・ホーム画面用のアイコン（192・512px、ファビコンなど）
   - 紹介サイト（latte.makimura.me）のアイコン

## 確認のしかた（渡す前の目安）

- 画像を、指先ほどの大きさ（60px）に縮めて見て、ロゼッタだと分かる。
- 画像の中央を丸く切り抜いたとき、取っ手とカップの縁が欠けない。
