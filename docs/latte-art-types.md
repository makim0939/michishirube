# ラテアートの型（同梱の型の仕様）

同梱の型は `src/roadmaps/latte-art.json`。最初の1回だけ端末に入り、入ったあとの人のデータは変わらない。

## 項目

| 項目 | 同梱の型 | 利用者 |
|---|---|---|
| 名前 | あり | 変えられる |
| 前提 | あり（初期の順序を、開発者が示す） | 自由に付け替えられる |
| 説明・やり方 | **なし**（開発者は示さない） | 自分で書ける（記録の「うまくいった」のメモは、自分のコツに溜まる） |
| 参考の目安（旧：達成条件）・出典 | **項目ごと廃止** | なし |

- 説明・目安・出典を外した理由：「この型について」でしか使っておらず、「できた」の判定にも使っていないため。
- 前提は、複数あれば**どれか1つ**でよい（スワンのように、道がいくつもあるため）。前提は「おすすめの順」の目安で、先の型にも記録できる。
- 見本の絵は、型の名前で選ぶ（`src/ui/world.ts` の `patternFor`）。名前に「ハート」を含めばハートの絵になる。

## 初期の順序

```
ハート → チューリップ → ロゼッタ ─┬→ レイヤーハート → ウィングハート ─┐
                                  └→ ウィングチューリップ ────────────┴→ スワン（どちらかで可）
```

根拠は、技術の依存（先に身につけたい技術）。

| 型 | 前提 | 身につく技術 | 必要な技術 |
|---|---|---|---|
| ハート | なし | dot、pull-through | |
| チューリップ | ハート | push | dot、pull-through |
| ロゼッタ | チューリップ | wiggling（抽出・スチームが安定している必要があり、ストロークにもテクニックが要る） | push |
| レイヤーハート | ロゼッタ | symmetrical-wiggle | wiggling |
| ウィングチューリップ | ロゼッタ | wiggling-push（wiggling で作ったウィングの上に、チューリップを作る） | wiggling |
| ウィングハート | レイヤーハート | wiggling-push | symmetrical-wiggle |
| スワン | ウィングチューリップ または ウィングハート | （位置やストロークの工夫が要る） | wiggling-push、wiggling |

ウィングハートは、アプリ LatteSteps を参考に足した。

## 型を足す・直すとき

- 新しい型は、利用者が「型の一覧 → 型を追加」で自分で足せる。同梱は、新規の人に最初から入るだけで、既存の人には入らない。
- 保存データの項目は、足すだけで消さない（古い端末の同期・バックアップが届くため）。
- 原因ボタン（`src/domain/causes.ts`）は、記録に文字列のまま保存して集計する。名前は変えず、足す。
