# アプリ内課金（投げ銭・ラテ帳 Plus）

iPhone・iPad のアプリだけ（Android は、リリースの準備ができてから足す）。プラグインは `@capgo/native-purchases`（StoreKit 2。購入の情報は、サーバーにも第三者にも送らない）。コードは `src/data/purchases.ts`、画面は `src/ui/SupportRows.tsx`（設定の「その他」）。

## 方針

- 買ったかどうかは、**ストアの購入履歴（Apple ID に紐づく）を正**にする。アプリのアカウント・サーバーには置かない。ログインしなくても、機種変更・入れ直しのあと「購入を復元」で戻せる。
- 端末には、結果だけ（`meta` の `purchase:plus`。同期・バックアップに入れない）を覚え、電波がなくても使えるようにする。返金は、次に起動したとき、ストアに問い合わせて反映する。
- 無料で使えていた機能（記録・保存・基本のトリミング・YouTube への公開・同期）は有料にしない。有料にするのは、新しく足す動画の仕上げ機能（つなぐ・BGM・文字）だけ。**YouTube へのアップロード自体は、課金の関門にしない**（YouTube API の規約。`references/video-edit-feasibility.md` の G-6）。
- App Store の「アプリのプライバシー」：購入の情報は、ストア（Apple）が持ち、アプリ・サーバーでは集めない。第三者の課金 SDK（RevenueCat など）を入れる場合は、申告とプライバシーポリシーの見直しが要る。

## 商品（App Store Connect に、同じ ID で登録する）

| ID | 種類 | 中身 |
|---|---|---|
| `me.makimura.lattecho.app.tip` | 消耗型 | 投げ銭。何も解放しない（Apple のガイドライン 3.1.1 は、アプリ内の投げ銭を認めている） |
| `me.makimura.lattecho.app.plus` | 非消費型 | ラテ帳 Plus（買い切り）。最初は ¥800 前後。解放するのは「動画をつなぐ」（記録の編集画面）。最初の 3 回は無料で試せる（画面は誰でも開ける。「完了」で、2 本以上をつなぐ（1 本を分割して 2 区間以上にするのも同じ）か BGM を入れていて、回数を使い切っているときだけ購入シートを出す。切り取りだけ・音を消すだけは、いつでも無料で、回数に数えない）。**ストアから Plus の商品が一度も取れたことがないとき（未登録・未承認）は、止めずに使える**（買えないのに、使えなくならないように）。一度でも取れたあとは、電波がなくても制限を外さない。設定の購入の行も、商品が取れたときだけ出る |

価格・名前は、ストアのものを画面に出す（コードに書かない）。

## 出すまでにやること（作者）

1. App Store Connect の「契約」で、有料アプリの契約・銀行口座・税務情報を済ませる。Small Business Program を申請する（手数料 15%）。
2. アプリ内課金に、上の商品を登録する（名前・価格・審査用のスクリーンショット）。最初の版では、`tip` だけ。
3. 日本の特定商取引法に基づく表記（紹介サイト）：氏名と問い合わせ先を載せ、住所・電話は「請求があれば遅滞なく開示する」とする（消費者庁の Q&A のとおり、すぐ開示できる体制が要る）。
4. EU で配信する場合は、App Store Connect の Trader 情報（住所・電話・メール）が EU の商品ページに出る。出したくなければ、EU での配信を外す。
5. 実機の確認：TestFlight（または Xcode から実機）で、サンドボックスのアカウントを使い、投げ銭を買えること・取り消せることを見る。

## 確認

- 商品がストアに無い環境（シミュレーター・商品の登録前）では、投げ銭の行は出ない。登録した商品が取れると出る（買う操作の確認は、実機）。
- 単体のテスト：`src/data/purchases.test.ts`（判定・覚え方・復元・取り消し・失敗）。
