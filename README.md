# 道しるべ（michishirube）

趣味や勉強の「プロが通ってきた道」をロードマップにして、日々の練習記録をそのロードマップのスキルに紐づけるアプリです。スマホのホーム画面に追加して使う PWA です。

- **ロードマップ**：スキルを前提条件でつないだツリー。前提をすべて達成すると次のスキルが解放されます。スキルごとに「達成条件」と「出典」を持ちます。
- **練習の記録**：挑戦中のスキルを選んで、動画・写真を撮り、「なぜそうなった？」と「次の一手」を書くだけ。次に記録するとき、前回の「次の一手」が一番上に出ます。
- **上達の見える化**：スキルごとに、最初と最新の動画・写真を並べて比べられます。
- **記録タブ**：全部のスキルの記録を新しい順に見返せます。記録はあとから直せます（結果・理由・次の一手、動画・写真の追加・削除）。
- **動画の切り取り**：始めと終わりを選んで、動画を短く作り直せます（選んだ長さぶんの時間がかかります）。
- **集中**：同時に「挑戦中」にできるスキルは全分野の合計で 3 つまで（設定で 1〜5）。
- **並行練習**：前提のスキルが「挑戦中」なら、次のスキルも並行して挑戦・記録できます（スチームを練習しながら、同じミルクでハートも練習するなど）。「達成」にできるのは、前提を達成してからです。
- **参考資料**：スキルごとに、何度も見返す動画や記事のリンクとメモを保存し、記録画面からすぐ開けます。
- **解除演出**：達成すると、新しく解放されたスキルと一緒に実績解除の演出が出ます。

最初からラテアートのロードマップ（10 スキル。レイヤーハートだけは出典がなく、達成条件を自分で決める）が入っています。

## 使い方

1. 「今日」タブの「挑戦できるスキル」から、挑戦するスキルを選ぶ
2. 練習カードをタップ → 動画を撮る（アプリ内のカメラで、容量を抑えて録画）→ 理由と次の一手を書く（キーボードのマイクで音声入力できます）→ 保存
3. 達成条件を満たしたら、スキルの画面で「達成した」を押す

## データの保存について

- 記録・動画・写真は、まず**端末のブラウザの中（IndexedDB）**に保存します。オフラインでも使えます。
- **クラウド同期**（[設定手順](docs/setup.md)）をつなぐと、記録・ロードマップ・写真は自分の Cloudflare（Workers + D1、無料プラン）に、動画は自分の YouTube チャンネルに「非公開」で自動的に保存されます。スマホの空きが少なくて端末のデータが消えても戻せ、PC とも同期できます。
- YouTube に上げ終えた古い動画は、端末から自動で整理します（スキルごとの最初の1本・最新3本・「残す」印のものは残します）。
- iPhone では、Safari で開いたままにせず「共有 → ホーム画面に追加」から開いてください。
- 「設定 → バックアップ」から ZIP の書き出し・復元もできます。
- 動画が多くてバックアップが 1.5GB を超えるときは、複数の ZIP に分けて書き出します（ZIP の 4GB の上限を避けるため）。復元するときは、全部の ZIP をまとめて選んでください。

## ロードマップの JSON 形式

「ロードマップ → ロードマップの JSON を読み込む」から、別の分野のロードマップを追加できます。各分野の画面から、今のロードマップを同じ形式で書き出すこともできます。

```json
{
  "version": 1,
  "domain": "ピアノ",
  "skills": [
    {
      "key": "c-major-scale",
      "name": "ハ長調のスケール（両手）",
      "description": "やり方や練習法",
      "criteria": "メトロノーム♩=80で、両手2オクターブを3回連続でミスなく弾ける",
      "sources": [{ "title": "出典のタイトル", "url": "https://example.com" }],
      "prereqs": []
    }
  ]
}
```

- `key` はファイル内でスキルを区別する文字列で、`prereqs` に前提スキルの `key` を並べます。
- 達成条件（`criteria`）は、回数や状態で判定できる書き方にしてください。
- 同梱のロードマップは、出典に書かれている内容だけで作り、出典に基準がないスキルは「自分で決めて書き換える」としています。

## 開発

```bash
pnpm install
pnpm dev        # 開発サーバー
pnpm test       # テスト（Vitest + fake-indexeddb）
pnpm typecheck
pnpm build      # dist/ に PWA を出力
```

- 構成：Vite + React + TypeScript、IndexedDB は Dexie、ツリーは React Flow + dagre、PWA は vite-plugin-pwa
- サーバー：`worker/`（Cloudflare Workers + Hono + D1）。`pnpm worker:dev` でローカル起動（`worker/.dev.vars.example` を `.dev.vars` にコピーして APP_TOKEN を入れる）。アプリとサーバーの通信の形は `shared/protocol.ts`
- `main` に入ると GitHub Actions で GitHub Pages にデプロイされます（`BASE_PATH` にリポジトリ名を入れてビルド）
- アイコンは `public/icon.svg` から `pnpm icons` で生成します
