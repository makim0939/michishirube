# ラテリエ（Latelier）

ラテアートの練習を1杯ずつ撮って残し、プロが通ってきた道すじ（ロードマップ）の上で「次に練習する型」を示すアプリです。スマホのホーム画面に追加して使う PWA です。（旧称「道しるべ」。リポジトリ名は michishirube のままです）

- **今日**：最新の1杯の写真を大きく出し、その下に練習中の型・前回の「次の一手」・「n杯目を撮る」・最近の杯を並べます。
- **型（ロードマップ）**：型を前提条件でつないだ道すじ。練習中・次に挑戦できる・その先・できた の順に、見本の絵と一緒に並べます。型ごとに「合格の目安」と「出典」を持ちます。
- **練習の記録**：「撮る」でアプリ内のカメラが開きます。動画・写真を撮り、「なぜそうなった？」と「次の一手」を書くだけ。次に撮るとき、前回の「次の一手」が一番上に出ます。
- **上達の見える化**：型ごとに、最初と最新の動画・写真を並べて比べられます。
- **カップ帳**：全部の型の記録を新しい順に見返せます。記録はあとから直せます（結果・理由・次の一手、動画・写真の追加・削除）。
- **動画の切り取り**：始めと終わりを選んで、動画を短く作り直せます（選んだ長さぶんの時間がかかります）。
- **集中**：同時に「練習中」にできる型は全分野の合計で 3 つまで（設定で 1〜5）。
- **並行練習**：前提の型を練習し始めれば、次の型も並行して練習・記録できます（スチームを練習しながら、同じミルクでハートも練習するなど）。「できた」にできるのは、前提ができてからです。
- **参考資料**：型ごとに、何度も見返す動画や記事のリンクとメモを保存し、記録画面からすぐ開けます。
- **できたときの演出**：「できた」にすると、次に目指せるようになった型と一緒に演出が出ます。

最初からラテアートのロードマップ（10 スキル、すべて出典つき）が入っています。

## 使い方

1. 「今日」タブの「挑戦できる型」から、練習する型の「はじめる」を押す
2. 「n杯目を撮る」→ 動画を撮る（アプリ内のカメラで、容量を抑えて録画）→ 結果・理由・次の一手を書く（キーボードのマイクで音声入力できます）→ 保存
3. 合格の目安を満たしたら、型の画面で「できた」を押す

## データの保存について

- 記録・動画・写真は、まず**端末のブラウザの中（IndexedDB）**に保存します。オフラインでも使えます。
- **クラウド同期**（[設定手順](docs/setup.md)）をつなぐと、記録・ロードマップ・写真は自分の Cloudflare（Workers + D1、無料プラン）に、動画は自分の YouTube チャンネルに「非公開」で自動的に保存されます。スマホの空きが少なくて端末のデータが消えても戻せ、PC とも同期できます。
- YouTube に上げ終えた古い動画は、端末から自動で整理します（型ごとの最初の1本・最新3本・「残す」印のものは残します）。
- iPhone では、Safari で開いたままにせず「共有 → ホーム画面に追加」から開いてください。
- 「設定 → バックアップ」から ZIP の書き出し・復元もできます。
- 動画が多くてバックアップが 1.5GB を超えるときは、複数の ZIP に分けて書き出します（ZIP の 4GB の上限を避けるため）。復元するときは、全部の ZIP をまとめて選んでください。

## ロードマップの JSON 形式

「型 → 型と分野の管理 → ロードマップの JSON を読み込む」から、別の分野のロードマップを追加できます。同じ場所から、今の分野のロードマップを同じ形式で書き出すこともできます。

```json
{
  "version": 1,
  "domain": "ピアノ",
  "skills": [
    {
      "key": "c-major-scale",
      "name": "ハ長調のスケール（両手）",
      "description": "やり方や練習法",
      "criteria": "メトロノーム♩=80で、両手2オクターブを3回連続でミスなく弾ける",
      "sources": [{ "title": "出典のタイトル", "url": "https://example.com" }],
      "prereqs": []
    }
  ]
}
```

- `key` はファイル内で型を区別する文字列で、`prereqs` に前提の型の `key` を並べます。
- 合格の目安（`criteria`）は、回数や状態で判定できる書き方にしてください。
- 同梱のロードマップは、出典に書かれている内容だけで作り、出典に基準がない型は「自分で決めて書き換える」としています。

## 開発

```bash
pnpm install
pnpm dev        # 開発サーバー
pnpm test       # テスト（Vitest + fake-indexeddb）
pnpm typecheck
pnpm build      # dist/ に PWA を出力
```

- 構成：Vite + React + TypeScript、IndexedDB は Dexie、PWA は vite-plugin-pwa。文字は Google Fonts（Zen Old Mincho・Zen Kaku Gothic New・Instrument Serif）
- サーバー：`worker/`（Cloudflare Workers + Hono + D1）。`pnpm worker:dev` でローカル起動（`worker/.dev.vars.example` を `.dev.vars` にコピーして APP_TOKEN を入れる）。アプリとサーバーの通信の形は `shared/protocol.ts`
- `main` に入ると GitHub Actions で GitHub Pages にデプロイされます（`BASE_PATH` にリポジトリ名を入れてビルド）
- アイコン（`public/pwa-*.png` など）と `public/world/` の絵（型の見本・時間帯の光）は、描き起こした画像をそのまま置いています。型の見本は、型の名前から `src/ui/world.ts` の `patternFor` で選びます
