# ラテ帳（らてちょう）

ラテアートの練習を1杯ずつ撮って残し、プロが通ってきた道すじ（ロードマップ）の上で「次に練習する型」を示すアプリです。スマホのホーム画面に追加して使う PWA です。（旧称「ラテリエ」「道しるべ」。リポジトリ名は michishirube のままです）

- **今日**：最新の1杯の写真を大きく出し、その下に練習中の型ごとに（最近練習した型が上）、前回の「次の一手」・「n杯目を記録する」・その型の最近の杯をまとめて並べます。杯を押すと、その1杯の動画・写真とメモを見返せます。
- **型（ロードマップ）**：型を前提条件でつないだ道すじを、つながりの図（ロードマップ）と一覧で見られます。型ごとに一般的な説明と「出典」（と任意の「参考の目安」）を持ち、型の画面の「この型について」で読めます。
- **練習の記録**：「n杯目を記録する」を押すと、すぐアプリ内のカメラが開きます。カメラの上に「今回意識すること」（前回の次の一手）が出ます。動画を撮ったらできあがりを1枚撮り、1画面で ◎△✕・原因のタグ・次の一手（前回と同じ・原因に応じた候補から選べる）を付けて「保存」か「保存してもう1杯」。メモは書きたいときだけ。写真だけ・アルバムからも残せます。
- **上達の見える化**：型ごとに、最新と最初の動画・写真を並べて比べられます。写真の下の「最新 ▾」から、好きな杯に入れ替えられます。
- **自分のコツ**：型ごとに、自分の記録から「いま意識していること」「つまずきやすいところ（直近の原因の回数）」「うまくいったときのメモ」をまとめて出します。
- **カップ帳**：全部の型の記録を新しい順に見返せます。記録はあとから編集できます（結果・原因・次の一手・メモ、動画・写真の追加・削除）。
- **動画の編集**：写真アプリのように、フィルムの両端の黄色い取っ手で範囲を決めて切り取り、スピーカーで音を消せます（作り直すので、選んだ長さぶんの時間がかかります）。
- **最近の調子**：決められた合格基準ではなく、型ごとに直近10杯の結果（◎△✕）を点で見せます。「できた」は自分で決めます。
- **自由に選べる**：ロードマップの前提は「おすすめの順」です。どの型でも、すぐ記録できます。「練習中」は自分で出し入れせず、最近（21日以内）に記録した型が自動で練習中になり、今日の画面に出ます（久しぶりに開いたときは、最後に記録した型が出ます）。
- **手本の動画・記事**：型ごとに、何度も見返す動画や記事のリンクとメモを保存し、撮るときにカメラの「手本」からすぐ開けます。
- **できたときの演出**：「できた」にすると、次のおすすめになった型と一緒に演出が出ます。

最初からラテアートのロードマップ（10 の型。レイヤーハートだけは出典がありません）が入っています。

## iOS アプリ（準備中）

App Store で配るため、同じ画面を Capacitor で iOS アプリに入れています（提出の手順は [docs/app-store-submission.md](docs/app-store-submission.md)）。

```bash
pnpm install
pnpm app:build   # アプリ用に作って ios/ へ入れる
pnpm app:ios     # 作って Xcode で開く（Xcode から実機・シミュレーターで動かす）
```

- 最新にするには、`git pull` して Xcode で実行するだけです。実行のたびに画面を作り直して入れます（`ios/App/scripts/build-web.sh`）。プラグインを足したときだけ `pnpm app:build` が要ります。画面を変えていないときに飛ばしたいなら、Xcode のスキームの環境変数に `SKIP_WEB_BUILD=1` を入れます。
- アプリ用の作りでは、画面のファイルを相対パスで読み、Web 版のオフライン用の仕組み（サービスワーカー）は入れません。
- カメラ・マイク・写真の許可の説明は `ios/App/App/Info.plist` にあります。

## Android アプリ（準備中）

iOS と同じ画面を、Capacitor で Android アプリに入れています。Google Play への提出の準備を進めています（手順は [docs/play-store-submission.md](docs/play-store-submission.md)）。

```bash
pnpm app:build                         # アプリ用に作って android/ へ入れる
cd android && ./gradlew assembleDebug  # 確認用の APK を作る（JDK 21 が要る）
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- Google Play に上げる署名つきの AAB は、`./gradlew bundleRelease -PrequireSigning`（鍵は `android/keystore.properties` に置く。git には入れない）。
- エミュレーターには H.264 のエンコーダーが無く、録画は WebM になります。録画まわりは、実機で確かめます。

## 使い方

1. 「今日」タブの「次のおすすめ」か「型」タブで、やってみたい型の「記録する」を押す（最近記録した型が「練習中」になり、今日の画面に出ます）
2. 「n杯目を記録する」→ カメラの上の「今回意識すること」を見て注ぐ → 動画を止めてできあがりを1枚 → ◎△✕・原因・次の一手を選ぶ → 「保存」（続けるなら「保存してもう1杯」）
3. 型のカードに出る「最近の調子」（直近10杯の◎△✕）を見て、納得できたら型の画面で「できた」を押す

## データの保存について

- 記録・動画・写真は、まず**端末のブラウザの中（IndexedDB）**に保存します。オフラインでも使えます。
- **Google でログイン**すると、記録・ロードマップ・縮小した写真がサーバー（Cloudflare Workers + D1）に置かれ、ほかの端末でも使えます。動画はサーバーに置かず、端末か、「動画」の保存先を YouTube にしたときは自分の YouTube チャンネルに置きます（YouTube の鍵も端末にだけ置きます）。サーバーの運営手順は [docs/setup.md](docs/setup.md)。
- 動画の保存先は、はじめは「この端末」です。YouTube にすると、上げてから3日たった動画を端末から消し、アプリの中で YouTube から再生します（消えたあとは編集できません）。
- iPhone では、Safari で開いたままにせず「共有 → ホーム画面に追加」から開いてください。
- 「設定 → バックアップ」から ZIP の書き出し・復元もできます。
- 動画が多くてバックアップが 1.5GB を超えるときは、複数の ZIP に分けて書き出します（ZIP の 4GB の上限を避けるため）。復元するときは、全部の ZIP をまとめて選んでください。

## ロードマップの JSON 形式

「設定 → ロードマップ → ロードマップの JSON を読み込む」から、別の分野のロードマップを追加できます。同じ画面の分野を押すと、その分野のロードマップを同じ形式で書き出すこともできます。

```json
{
  "version": 1,
  "domain": "ピアノ",
  "skills": [
    {
      "key": "c-major-scale",
      "name": "ハ長調のスケール（両手）",
      "description": "やり方や練習法",
      "criteria": "メトロノーム♩=80で、両手2オクターブを3回連続でミスなく弾ける",
      "sources": [{ "title": "出典のタイトル", "url": "https://example.com" }],
      "prereqs": []
    }
  ]
}
```

- `key` はファイル内で型を区別する文字列で、`prereqs` に前提の型の `key` を並べます。
- 参考の目安（`criteria`）は任意です。「できた」は、最近の調子を見て本人が決めます。
- 同梱のロードマップは、出典に書かれている内容だけで作り、出典に基準がない型は「自分で決めて書き換える」としています。

## 開発

```bash
pnpm install
pnpm dev        # 開発サーバー
pnpm test       # テスト（Vitest + fake-indexeddb）
pnpm typecheck
pnpm build      # dist/ に PWA を出力
```

- 構成：Vite + React + TypeScript、IndexedDB は Dexie、ロードマップの図は React Flow + dagre、PWA は vite-plugin-pwa。文字は Google Fonts（Zen Old Mincho・Zen Kaku Gothic New・Instrument Serif）
- サーバー：`worker/`（Cloudflare Workers + Hono + D1）。`pnpm worker:dev` でローカル起動（`worker/.dev.vars.example` を `.dev.vars` にコピーして APP_TOKEN を入れる）。アプリとサーバーの通信の形は `shared/protocol.ts`
- `main` に入ると GitHub Actions で GitHub Pages にデプロイされます（`BASE_PATH` にリポジトリ名を入れてビルド）
- サーバー（`worker/`・`shared/`）の変更が `main` に入ると、GitHub Actions が D1 のマイグレーションを当ててから Cloudflare にデプロイします（Environment「production」の Secrets に `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` が必要。main だけに限る。無ければ飛ばします。手順は [docs/setup.md](docs/setup.md) の 1-3）
- アイコン（`public/pwa-*.png` など）と `public/world/` の絵（型の見本・時間帯の光）は、描き起こした画像をそのまま置いています。型の見本は、型の名前から `src/ui/world.ts` の `patternFor` で選びます
