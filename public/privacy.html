ラテ帳 プライバシーポリシー

最終更新日：2026年10月15日 ・ English

「ラテ帳」（旧称「ラテリエ」「道しるべ」。以下「本アプリ」）は、個人がラテアートなどの練習を記録するためのアプリです。このページでは、本アプリが扱う情報と、その保存先を説明します。

1. 扱う情報と保存先

  • 練習の記録・ロードマップ・写真・動画：利用者の端末に保存します（Web 版はブラウザの中（IndexedDB）、iPhone・Android のアプリはアプリの中のファイル）。ログインしていなければ、端末の外には送りません。
  • Google でログインした場合：ほかの端末でも同じ記録を使えるよう、次のものを本アプリのサーバー（作者が運営する Cloudflare Workers・D1）に保存します。
    • 練習の記録（日時・結果・原因・メモ・次の一手）、型と分野（ロードマップ）、設定
    • 動画・写真の情報（種類・大きさ・撮った日時・YouTube の動画 ID）
    • 縮小した写真と、動画のサムネイル（できあがりの1コマ）
    • Google アカウントを見分けるための番号（Google の「sub」）と、ログイン中の端末を見分けるための値（ハッシュにして保存）
    動画の中身、Google アカウントのメールアドレス・名前・パスワード、YouTube の認可情報は、サーバーに記録として保存しません。 ただし、ログインや YouTube の連携の途中だけ、その結果（メールアドレス、YouTube の認可情報）を、端末が受け取るまでの間、サーバーのデータベースが一時的に預かります。端末が受け取った時点で、すぐに削除します。受け取られなかったものは、10分を過ぎると使えなくなり、次にだれかがログインを始めたときに削除されます。 サーバーのデータは、通信を暗号化して送り、ログインした本人の端末からだけ読み書きできます。作者は、障害の調査など運営に必要な場合を除いて、利用者のデータを見ません。
  • YouTube と連携し、動画の保存先を YouTube にした場合：利用者が撮った練習の動画を、利用者自身の YouTube チャンネルにアップロードします。動画は端末から YouTube へ直接送り、本アプリのサーバーを通しません。公開範囲は、はじめは「限定公開」（URL を知っている人だけが見られ、検索や一覧には出ません）で、利用者が設定で「公開」（だれでも見られ、検索にも出ます）を選んだときだけ公開します。
  • YouTube の動画をアプリの中で表示・再生する場合：YouTube の再生の仕組み（YouTube IFrame Player API・youtube-nocookie.com）と、動画のサムネイル（i.ytimg.com）を読み込みます。このとき、IP アドレスやブラウザの種類などの通信に必要な情報が Google に送られます。iPhone・Android のアプリでは、YouTube の決まり（埋め込むページが https であること）のため、本アプリのサイト（GitHub Pages）にある再生用のページを挟んで再生します。このページにも、通信に必要な情報（IP アドレスなど）が送られます（GitHub が受け取ります）。動画の ID 以外の記録・写真は送りません。
  • 文字の表示（フォント）：画面の文字の形（フォント）を Google Fonts から読み込みます。このとき、IP アドレスやブラウザの種類などの通信に必要な情報が Google に送られます。練習の記録・写真・動画は送りません。一度読み込んだフォントは端末に保存し、次からはそれを使います。

2. Google ユーザーデータの取り扱い

  • 本アプリが Google に求める権限は、ログインのための基本情報（openid・email）と、YouTube への動画のアップロード（https://www.googleapis.com/auth/youtube.upload）だけです。YouTube の権限は、利用者が YouTube と連携したときだけ求めます。
  • ログインで受け取るメールアドレスは、どのアカウントでログインしているかを端末に表示するためだけに使い、サーバーには記録として保存しません（上のとおり、端末が受け取るまでの一時的な預かりだけです）。
  • YouTube の権限は、利用者が本アプリで撮った動画を、利用者自身のチャンネルへアップロードするためだけに使います。チャンネルの動画の一覧や視聴履歴など、ほかの情報は読み取りません。
  • YouTube の認可情報（リフレッシュトークン）は、連携した端末の中にだけ保存します。連携の途中で、端末が受け取るまでの間だけ、サーバーのデータベースが一時的に預かります（受け取られたらすぐ削除します）。アップロードの前には、1時間で切れるアクセストークンに替えるため本アプリのサーバーに送りますが、サーバーには保存しません。
  • Google から受け取った情報を、第三者に提供・販売したり、広告に使ったり、人が読んだりすることはありません。本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的な使用の要件を含む）に従います。

3. YouTube API サービスについて

  • 本アプリは、YouTube API サービスを使っています。YouTube と連携して動画をアップロードするとき、利用者は YouTube 利用規約に拘束されることに同意したものとみなされます。アップロードする動画が、その規約に沿った内容であることを、利用者が確認したものとみなされます。アップロードする動画は「子ども向けではない」として設定します（変えるときは、YouTube で設定してください）。
  • Google がデータをどう扱うかは、Google プライバシー ポリシーを参照してください。
  • YouTube への連携は、Google のセキュリティ設定のアプリのアクセス許可のページから、いつでも取り消せます。取り消すと、本アプリは以後 YouTube にアクセスできません。

4. 保存期間・ログアウト・連携の解除・データの削除

  • サーバーに保存したデータは、利用者がアカウントを削除するまで保存します。アカウントを削除すると、すぐにサーバーから削除されます。
  • 「設定 → アカウント → ログアウト」で、その端末のログインを終えます（端末とサーバーの記録は残ります）。
  • 「設定 → アカウント → アカウントを削除」で、アカウントと、サーバーに保存したすべてのデータをすぐに削除します（端末の記録と、YouTube に上げた動画は残ります）。
  • 「設定 → アカウント → YouTube → 連携を解除」で、端末の認可情報を削除し、Google 側の許可も取り消します。
  • Google アカウントのサードパーティのアクセスからも、いつでも許可を取り消せます。
  • YouTube にアップロードした動画は、YouTube のアプリやサイトから削除できます。
  • 端末のデータは「設定 → この端末のデータを削除」で削除できます。

5. 第三者への提供

本アプリの作者は、利用者の情報を第三者に提供しません（法令に基づく場合を除く）。アクセス解析や広告のためのツールも使っていません。サーバーは Cloudflare（Workers・D1）を使っており、データは Cloudflare の設備に保存されます。

6. お問い合わせ

このポリシーや、データの扱いについてのご質問・苦情は、GitHub の Issues からご連絡ください。

7. このポリシーの変更

このポリシーを変えるときは、このページの「最終更新日」を更新します。Google に求める権限が増えるときは、Google の同意画面で、あらためて許可を求めます。
