ラテリエ プライバシーポリシー

最終更新日：2026年10月10日

「ラテリエ」（旧称「道しるべ」。以下「本アプリ」）は、個人がラテアートなどの練習を記録するためのアプリです。本アプリの作者は、利用者の情報を集めて保有するサーバーを運営していません。このページでは、本アプリが扱う情報と、その保存先を説明します。

1. 扱う情報と保存先

  • 練習の記録・ロードマップ・写真・動画：利用者の端末のブラウザの中（IndexedDB）に保存します。
  • クラウド同期を設定した場合：記録・ロードマップ・縮小した写真を、利用者自身が用意した Cloudflare のアカウント（Workers・D1）に保存します。作者はこのデータにアクセスできません。
  • YouTube と連携した場合：利用者が撮った練習の動画を、利用者自身の YouTube チャンネルに「非公開」でアップロードします。

2. Google ユーザーデータの取り扱い

  • 本アプリが Google に求める権限は、YouTube への動画のアップロード（https://www.googleapis.com/auth/youtube.upload）だけです。
  • この権限は、利用者が本アプリで撮った動画を、利用者自身のチャンネルへアップロードするためだけに使います。チャンネルの動画の一覧や視聴履歴など、ほかの情報は読み取りません。
  • 連携のために Google から受け取る認可情報（リフレッシュトークン）は、利用者自身の Cloudflare アカウントのサーバー（D1）にだけ保存します。端末には、1時間で切れるアクセストークンだけを渡します。
  • Google から受け取った情報を、第三者に提供・販売したり、広告に使ったり、人が読んだりすることはありません。本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的な使用の要件を含む）に従います。

3. 連携の解除とデータの削除

  • 本アプリの「設定 → YouTube → 連携を解除」で、保存している認可情報を削除し、Google 側の許可も取り消します。
  • Google アカウントのサードパーティのアクセスからも、いつでも許可を取り消せます。
  • YouTube にアップロードした動画は、YouTube のアプリやサイトから削除できます。
  • 端末のデータは「設定 → この端末のデータをすべて削除」で、サーバーのデータは利用者自身の Cloudflare アカウントから削除できます。

4. 第三者への提供

本アプリの作者は、利用者の情報を第三者に提供しません。アクセス解析や広告のためのツールも使っていません。
